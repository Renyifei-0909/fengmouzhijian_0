# 合成设计包样例（非真实现场）

本目录提供 **Alpha18** 垂直切片使用的脱敏/合成设计包 JSON。

## 真实性边界

- `synthetic: true`：坐标与对象均为演示构造；
- CRS 使用 `EPSG:25832`（与归档 QGIS 项目一致），导入时会转换到 WGS84；
- **不是** 真实工地、不是训练集、不是 90% 指标依据；
- 不得用本样例冒充授权原件或真实现场 GPS。

## 文件

- `synthetic-pipe-route-package.json`：一条管线路由 `PIPE-101`，预期 4 根可见管线、工序 `laying`。
