## 当前建议

首个正式量化主线暂定为：

> 施工视频中的人员—PPE 感知、人员/PPE 归属和轨迹级违章事件判定；第一阶段只承诺安全帽，反光背心必须在获得 `vest_off` 真值后再进入正式指标。

隐蔽工程路线保留为产品能力与受限技术预研：覆土前影像采集、三维重建、管线/沟槽分割、人工复核、结构化记录和哈希存证。未取得标定、尺度基准与独立测量真值前，不输出“工程级精确埋深/间距”或“已达到 90%”的结论。

这不是最终团队决策。Construction-PPE 下载审计又发现官方 split 存在跨集合近重复和 10 个孤立标签，路线 B 当前修正为 72/100。只有 `TWO_DAY_ROUTE_GATE.md` 的门禁通过并由项目统筹、算法/数据负责人和 QA 确认后，路线状态才可改为 `accepted`。

## 不可越过的真实性边界

1. 公开数据只用于预训练、基线或辅助验证，不能替代通信施工现场的授权盲测视频。
2. 静态图像目标检测的 mAP 不能直接写成“视频违章识别准确率”。
3. 预切事件窗分类达到 85% 不能证明未剪辑长视频能自动发现全部事件；后者需要时序定位与漏检评测。
4. `stub`、`demo_fixture`、mock、人工填入结果和合成占位数据不得进入正式 EvaluationRun。
5. 数据“可下载”不等于可用于企业命题比赛、公开答辩、模型权重发布或商业化。
6. 单目深度没有标定、尺度控制和独立测量真值时，不是工程尺寸验真的证据。
7. 当前所有数值均为路线规划或来源事实；项目尚无正式 85%/90% 结果。
8. development runner 只可用于 `train`/`validation` 联调；它不隔离同 UID 可读文件或网络，不能用来证明模型未见 private labels，也不能代替 QA 正式盲测。

## 研究方法与披露

本轮为工程可行性的定向快速调研，优先使用数据集作者仓库、官方数据页、原始论文、许可证正文和政府标准；不是完整数据库覆盖的系统综述。候选许可结论用于工程筛选，不构成法律意见。正式采用时仍须保存下载页、LICENSE、引用、下载日期、原始文件摘要和书面授权。
