# 数据、隐私与授权边界

## 1. 现有归档能用到什么程度

递归盘点结果：

- 6 份规范/流程 PDF；
- 13 张 BAKTI 现场 JPEG；
- 14 个 GeoPackage、1 个主要 QGIS 工程和相关配置；
- 12,406 条 GIS/QField 记录；
- 没有施工视频；
- 没有 bbox、mask、关键点、违规/合格标签或冻结评测集。

因此它们可用于领域建模、规则字段设计、匿名化界面样例和 smoke test，但不能单独训练或证明 85%/90%。

## 2. 敏感信息

- QGIS 数据含真实地址、姓名、邮箱、电话、精确空间坐标和外部附件路径；
- 现场照片含时间、经纬度、方向、站点编号水印，部分 EXIF 保留 GPS、设备和拍摄时间；
- 多数 QGIS 附件只有引用路径，原文件并未随包提供；
- 资料未附带公开许可、训练授权或第三方服务上传许可。

不得执行：

- 将原始 QGIS 包放入公开仓库或答辩附件；
- 把含坐标/人员信息的图片上传到未获授权的第三方模型 API；
- 把 13 张图称为训练集、测试集或 90% 指标依据；
- 把不同国家、项目、年份的规范阈值混成一个统一强制标准；
- 在未复核 OCR 的情况下把扫描 PDF 数值直接写入规则引擎。

## 3. 建议的数据登记表

每个来源至少登记：

- 来源名称和取得方式；
- 权利人/提供方；
- 允许用途：研究、训练、内部演示、公开答辩、再分发；
- 是否含个人信息、位置、商业秘密；
- 脱敏方法和派生数据摘要；
- 保留期限和删除责任人；
- 标签规范和审核人；
- train/validation/test 划分摘要；
- 禁止上传的外部服务。

## 4. 公开演示副本流程

1. 原件只进入受控存储并计算摘要；
2. 生成派生副本，清除 EXIF；
3. 模糊人脸、姓名、电话、站点 ID、经纬度和精确地址；
4. 裁剪到与算法/界面必要的区域；
5. 记录原件 ID、派生规则和派生文件摘要；
6. 由数据负责人和项目负责人批准公开用途；
7. 最终提交包只包含获批副本。

## 5. 远程算法的数据外传边界

`remote_http` 只是默认关闭的技术桥接，`compose.yaml` 也显式保持
`FENGMOU_REMOTE_ANALYZER_ENABLED=false`。它不提供数据授权，也不表示真实算法已接入。
任何人不得仅为了联调而打开该开关。

当前这些要求仍由部署审批和数据治理流程人工执行：代码尚未实现批准单、脱敏派生物、保留期限和删除回执的强制门禁，远程桥也不会自动识别人脸、水印、EXIF 或画面中的人员/位置文字。在这些门禁完成前，不得对真实数据启用 `remote_http`。

启用前必须由数据负责人和项目负责人完成书面批准，并在数据登记表中至少锁定：

- 允许外传的数据源、业务目的、必要字段与是否允许发送原件；
- 固定的接收主体、endpoint、部署地域/数据出境情况及所有下游处理方；
- 服务端对原件、请求/响应、缓存、日志与备份的分项保留期限；
- 到期删除、用户撤回授权或事故响应时的责任人、时限和可验证删除证明；
- 是否禁止上游把数据用于模型训练、二次分析、产品改进或其他目的。

执行时的最小化要求：

1. 优先发送经批准的脱敏派生副本；只有授权明确覆盖原件时才可发送原件。
2. 不得把 API 密钥、人员信息、精确位置或与推理无关的业务元数据放入媒体或请求字段；远程 Bearer 密钥只保存在后端。
3. 记录批准单号、任务 ID、原件/派生副本 SHA-256、接收 endpoint 身份、模型制品摘要、发送时间与删除截止日期；审计日志不记录密钥或媒体原文。
4. 上游若不能提供保留/删除策略、存在未批准下游转发，或响应与锁定模型身份不一致，必须停止外传并关闭远程开关。
5. 上游单样本输出始终按未评测结果处理；人工复核不等于授权它作为准确率、比赛指标或最终验收依据。

授权到期、范围变更或答辩结束后，应同时删除本地不再必要的中间副本和远程侧原件、缓存、日志/备份派生数据，保留不含敏感原文的删除回执与审计记录。

## 6. 正式评估最小门槛

- 选定唯一任务主线和样本单元；
- 给出类别/字段、缺失值、低置信度和忽略规则；
- 按视频/工程实体切分，避免相邻帧泄漏；
- 冻结真值、split digest、metric spec 和评估脚本；
- 同时报告官方 accuracy 和 precision/recall/F1 或字段级明细；
- 保留 TP/FP/TN/FN 或字段匹配的样本级结果；
- mock/fixture 不得进入 EvaluationRun；
- 未达标时报告真实数值和差距，不改变分母或删失败样本。

算法路线、候选数据许可、正式来源登记字段、数据卡和标签/指标讨论稿已汇总到 `docs/algorithm-data/`。该目录中的 `candidate-now` 仍不是自动授权：正式采用时必须保存许可证原文、下载日期、原始制品摘要和用途批准；`unknown` 一律按不允许处理。
