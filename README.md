# 多源感知赋能端边云协同的智能监管与可信交付系统

---

## 一、 项目背景与系统定位

随着 5G-A 规模化商用、算力网络全域布局与千兆光网深度覆盖，通信基础设施建设呈现出**点位分散、线路跨度大、野外场景多、隐蔽工序多、建设标准严苛**的新特征。传统通信工程监管模式过度依赖人工巡查、纸质记录与事后抽检，长期存在**监管盲区多、隐蔽工程数据黑箱、竣工资产账物不符、全生命周期溯源困难**等核心行业痛点。

本项目**《多源感知赋能端边云协同的智能监管与可信交付系统》**，彻底摒弃传统被动监管模式，构建了覆盖**移动近场采信 + 边缘实时智算 + 云端图物对齐 + AI 隐蔽工程验真 + 哈希防篡改存证**的全链条数字化解决方案。系统统一采用**科技蓝（Tech Blue）视觉规范**，提供了高保真、可交互、多端适配的系统成品。

---

## 二、 核心痛点与本系统解决方案

| 传统通信工程痛点 | 传统模式瓶颈 | 本系统端边云协同应对策略 |
| :--- | :--- | :--- |
| **监管存在盲区与极强滞后性** | 露天/野外长线路施工，固定监控难以全覆盖；人工上报易出现瞒报、误报与延迟。 | **多源异构设备统一接入 + 边缘侧实时预警**：兼容 RTSP 视频流、智能安全帽、传感器，边缘节点实现违章毫秒级识别与本地预警。 |
| **隐蔽工程数据黑箱** | 管线敷设、沟槽开挖等隐蔽工序完成后即被覆土，二次核查成本高、易造假。 | **隐蔽工程影像结构化 AI 自动验真**：语义分割 + 深度量测，自动输出埋深、间距、规格与数量，给出通过/复检客观结论。 |
| **竣工资产数据失真，难以溯源** | 普通电子文档与纸质记录可篡改、易替换、无唯一标识，运维追责困难。 | **基于哈希特征树的可信数字交付**：SHA-256 哈希加密封装，施工实景、AI 参数、整改记录全程留痕、不可篡改、上链可查。 |
| **工地弱网断网环境系统失效** | 野外施工网络波动频繁，云端系统常因断网导致监管中断与数据丢失。 | **端边协同自适应视算调度与断点续传**：高频低算力任务下沉边缘，弱网状态本地缓存，网络恢复后自动同步至云端。 |

## 三、 整体架构与 UI 设计规范

### 1. 统一全局科技蓝（Tech Blue）视觉标准
- **配色体系**：以深蓝色（`#07111f` ~ `#0d1b36`）为侧边栏基底，科技湛蓝（`#1677ff` / `#0958d9`）为主色调，天蓝/青蓝（`#38bdf8` / `#06b6d4`）为高亮点缀，辅以浅灰背景（`#f8fafc`）与纯白卡片，营造明亮、专业、精致的工控科技质感。
- **布局层级**：统一的 28px/32px 大圆角卡片、微阴影（`shadow-sm` 至 `shadow-xl`）、毛玻璃（`backdrop-blur`）顶栏与平滑的淡入上浮页面过渡动画（`page-enter`）。
- **多端适配**：支持桌面端全屏展现，并在移动端/小屏设备下自动提供顶部快捷导航组件（`MobileQuickNav`），确保所有按钮与操作流在不同屏幕尺寸下均可流畅点击。

### 2. 端-边-云协同架构设计
```
┌──────────────────────────────────────────────────────────────────────────┐
│                             感知端 (Sensing Layer)                       │
│  [固定监控 RTSP 流]   [智能安全帽高清模块]   [手机 APP 采信]   [IoT 传感器] │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │ 原始数据采集 / 弱网本地缓存
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                             边缘侧 (Edge Layer)                          │
│   [Jetson 边缘 AI 计算盒子] -- 实时解码 / 安全违章抓拍 / 本地声光告警   │
└────────────────────────────────────┬─────────────────────────────────────┘
                                     │ 结果按需上传 / 弱网续传
                                     ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                            核心云端 (Cloud Layer)                        │
│  [AI 隐蔽工程自动验真]  [GIS 图物动态对齐]  [进度核算]  [哈希上链可信存证] │
└──────────────────────────────────────────────────────────────────────────┘
```

## 四、 系统全量功能模块详解

系统共包含 **13 个核心页面/业务视图**，每个页面均已完整开发，无死链、无无法点击的按钮，并均配有丰富的提示反馈与 Modal 交互：

### 1. 监管总览 (`/dashboard` - DashboardPage)
- **工程全景看板**：展示在建项目数、在线感知设备、今日告警数与平均施工进度。
- **隐蔽工程 AI 验真核心引向区**：展示 5 步 AI 验真演示流程、识别精度（>90%）、平均耗时（3.2s）等核心指标，并支持一键进入验真页面。
- **快捷业务入口卡片**：直接跳转至 GIS 地图、数据看板、溯源查询与模型服务 Demo。
- **多维图表与数据榜**：展示各项目施工进度排名榜与最新告警事件流。

### 2. 隐蔽验真 AI (`/ai-verification` - HiddenAIPage)
- **场景切换 Demo**：支持“通信管道排布验真”（管道井）、“沟槽开挖深度验真”（隐蔽沟槽）、“线缆预埋与覆土验真”（预埋点）三大样例场景。
- **5 步自动化分析流程**：演示“影像接入 → 语义分割 → 参数量测 → 规则比对 → 可信封装”全过程，配有步骤节点高亮与动画。
- **结构化参数输出**：量化测算识别得分、模型置信度、埋深、间距、设施规格与目标数量，并给出客观结论（通过 / 需复检 / 不通过）。
- **风险点与整改建议**：客观列出违规风险点（如覆土厚度不足、警示带缺失等）与可落地的整改建议。
- **原图与 AI 叠加对比 Modal**：提供标注热区/轮廓与原图对照查看。
- **结构化数据预览 Modal**：提供标准化 JSON/表格字段预览，并支持一键推送至业务系统。
- **可信动作**：包含导出 AI 报告、打印验真单、哈希上链存证与发起整改复检。

### 3. GIS 地图 (`/gis-map` - GISMapPage)
- **地图空间点位联动**：在科技蓝平板地图上绘制多个施工工程标注点位，支持点击切换选中项目。
- **图物动态对齐面板**：显示选中点位对应的工程名称、施工位置、进度比例、相机数量与现场告警数。
- **联动操作**：可从地图选中点位直接跳转至该项目的详细监管页，或一键跳转至 AI 验真中心，并支持生成 GIS 对齐证据快照。

### 4. 数据看板 (`/data-cockpit` - DataCockpitPage)
- **施工监管驾驶舱**：汇总在建项目、在线设备、今日告警与平均完成率。
- **多周期走势图表**：支持按“日 / 周 / 月”动态切换综合运行指数柱状图。
- **设备与告警结构占比**：展示各类硬件在线数比例以及安全/质量/设备告警结构的统计占比。
- **快照导出**：支持一键导出驾驶舱当前状态快照。

### 5. 项目管理 (`/projects` - ProjectsPage)
- **项目全景网格**：展示所有通信基建工程（如 5G 骨干光缆、算力网络扩容、乡村管线改造等）的概况、负责人、施工时间与进度条。
- **状态筛选**：支持“全部 / 进行中 / 待启动 / 已暂停 / 已完成”状态过滤。
- **新建演示项目 Modal**：包含表单校验，可输入项目名称、地点、负责人与说明，提交后提供实时成功提示。

### 6. 项目详情 (`/projects/:id` - ProjectDetailPage)
- **深维度工程面板**：展示单项目的参与人数、监控点位、设备接入数与活跃告警数。
- **Tab 选项卡切换**：
  - **总览**：项目阶段进度条（设计、施工、隐蔽验真、验收、交付）与建议动作。
  - **设备**：查看该项目关联的硬件设备列表并可点击弹窗查看设备详情。
  - **报表**：查看该项目关联的质检/安全/进度报表，支持下载 Modal。
  - **可信档案**：演示该项目数字交付档案生成、核验真伪与上链存证。
- **一键动作**：提供打印、导出资料、采集上报与跳转 AI 验真入口。

### 7. 告警中心 (`/alarms` - AlarmsPage)
- **多维度告警流**：涵盖安全违章（未戴安全帽、危险区域闯入）、工艺偏差（管材排列偏差）、设备异常（离线超过 24h）与进度上报。
- **分类标识**：按严重（红色）、警告（黄色）、信息（蓝色）分级展示，支持关键词搜索与处理状态过滤（未处理 / 已处理）。
- **确认处理与详情 Modal**：未处理告警可一键“确认处理”并更新状态，查看 Modal 中提供针对该告警的客观处置建议。

### 8. 设备监控 (`/devices` - DevicesPage)
- **多源异构设备清单**：监控摄像头、温湿度传感器、边缘 AI 盒子（Jetson 系列）、智能安全帽。
- **状态与心跳监管**：实时显示设备在线、离线、预警、故障状态及电池电量/最后心跳时间。
- **设备类型过滤**：支持按摄像头、传感器、边缘盒子、安全帽进行筛选。
- **批量诊断与设备详情 Modal**：支持一键发起批量诊断，点击特定设备可弹窗查看详细部署参数与发起远程巡检。

### 9. 数据分析 (`/analytics` - AnalyticsPage)
- **7日告警趋势图**：直观展示安全、质量与设备告警的周走势。
- **项目进度对比图**：横向对比各大通信工程的当前进度。
- **设备类型分布图**：展示硬件接入构成，并支持导出分析报表。

### 10. 报表中心 (`/reports` - ReportsPage)
- **多类型报表列表**：涵盖工程质量周报、安全监管月报、隐蔽工程核验专项报告、施工进度报告等。
- **状态与文件参数**：展示生成状态（已生成 / 生成中）、文件大小与周期。
- **报表预览与下载 Modal**：可点击预览 Modal 查看汇总内容，并支持单文件下载、全部导出与直接打印。

### 11. 溯源查询 (`/traceability` - TraceabilityPage)
- **数字档案真伪核验**：通过档案编号（如 `ARC-2026-001`）或 SHA-256 哈希指纹进行双重检索。
- **全流程时间线 Modal**：展示从“现场采集 → AI 验真 → 整改复核 → 哈希存证 → 交付档案生成”的完整链路。
- **一键动作**：支持复制哈希指纹与导出核验单。

### 12. 模型服务 (`/model-service` - ModelServicePage)
- **端边云模型编排面板**：管理边缘违章检测、隐蔽工程结构化验真、图物对齐进度核算、弱网任务补偿调度等 AI 模型。
- **模型启停控制**：可直接切换模型的运行/空闲状态，并实时反馈。
- **性能指标与压测**：展示模型版本、准确率与推理时延，支持版本切换、性能压测、边缘下发。
- **推理结果预览 Modal**：展示模型实际推理输出摘要与识别目标数。

### 13. 账户设置与系统设置 (`/settings/account`, `/settings/system`)
- **账户设置**：支持修改个人姓名/手机/邮箱/部门，进行头像更换模拟、双因素认证、重置密码与通知偏好（告警/周报/登录/短信）开关。
- **系统设置**：提供端边云协同模式选择（端边云协同 / 边缘优先 / 云端集中）、数据保留天数、日志等级配置，以及弱网缓存、全量审计日志、边缘本地缓存、自动归档开关，并提供数据库/边缘节点联通性测试与健康巡检动作。

## 五、 项目快速上手与部署指南

### 1. 环境准备
- **Node.js**：建议 `v18.0.0` 或更高版本
- **包管理器**：`npm` / `pnpm` / `yarn`

### 2. 开发环境运行
```bash
# 1. 进入项目根目录并安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```
启动后在浏览器打开提示的本地地址（通常为 `http://localhost:5173`）即可体验系统。

### 3. 生产环境打包部署
```bash
# 执行生产环境构建
npm run build
```
构建成功后将生成 `dist` 目录，其中包含打包合并后的静态资源（如 `dist/index.html`）。将 `dist` 目录直接部署至 Nginx、Apache 或静态 Web 托管服务即可使用。
